# Panchangam Viewer

A single-page viewer for the consolidated `.json` results the
`predicting-favorable-time-per-panchangam` skill writes, e.g.
`Jai_output_dir/Jai/Chennai/Jai_September_2026_3.json`.

- **Open JSON file(s)**, **drag and drop**, or **Open output folder** to load every
  prediction under a `{person}_output_dir/` at once (one tab per person/city/window).
- List view with a 24-hour bar for each favorable window, plus a month calendar view.
- Filter by weekday (every *requested* weekday is shown with its count; one with no favorable dates appears greyed out as `0`, so it isn't mistaken for not having been requested), full days only, or hide past dates. Highlights today and the next
  favorable day. Prints cleanly. Light and dark themes.
- **Privacy:** files are read with the browser's File API and never leave your
  machine. The page has no backend and makes no network requests besides loading
  React/htm from a CDN (pinned with Subresource Integrity hashes).

## Use it

- Hosted: https://sreenaathkv.github.io/predicting-favorable-time-per-panchangam/
  (deployed from this folder by `.github/workflows/pages.yml`).
- Locally: open `viewer/index.html` directly in a browser. No build or server needed.

Browsers can't read your home directory on their own, so you pick the file or folder
once through the file dialog.

## Development

Plain HTML + React 18 (UMD) + [htm](https://github.com/developit/htm) for JSX-like
templates, so there's no toolchain: edit `index.html` and refresh. The embedded
`sample-data` block is a non-personal example (a fictional "Example" person in
Chennai) generated by the skill. If the JSON schema written by
`collate_and_save_predictions` in `panchangam_utils.py` changes, update `validate()`
and `parsePrediction()` here too.
